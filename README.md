🚀 O que é
O EletroDiagnóstico é uma ferramenta prática que auxilia estudantes, eletricistas e técnicos a organizar o raciocínio diante de falhas elétricas comuns. Funciona 100% no navegador, sem instalação, sem backend e sem conexão com a internet.

✨ Funcionalidades
Assistente de diagnóstico interativo — selecione um sintoma, responda perguntas objetivas e veja as hipóteses mais prováveis serem ranqueadas com justificativas técnicas.

Indicador de Prioridade Diagnóstica — barras visuais que se ajustam conforme suas respostas (classificação heurística, não probabilidade).

Biblioteca de símbolos elétricos — pesquisa e filtros por categoria, com descrições e observações.

Esquemas didáticos — diagramas vetoriais de comandos elétricos básicos (partida direta, selo, reversão, etc.).

Desafios técnicos — modo de aprendizagem com perguntas comentadas e pontuação.

Histórico local — salve, consulte, exclua registros e imprima relatórios em PDF pelo navegador.

Design responsivo — funciona em celular, tablet e computador, com tema escuro profissional.

🛠️ Tecnologias
HTML5

CSS3

JavaScript puro (sem bibliotecas externas)

📂 Como usar
Baixe o arquivo index.html.

Abra no seu navegador (Chrome, Firefox, Edge, etc.).

Pronto! Não precisa de servidor.

Também pode ser hospedado gratuitamente em serviços como GitHub Pages, Netlify ou Vercel.

⚠️ Segurança e Limitações
Este aplicativo é uma ferramenta educacional de apoio ao raciocínio técnico. Não substitui:

Inspeção presencial;

Diagramas oficiais e manuais de fabricantes;

Procedimentos de bloqueio e etiquetagem (LOTO);

Normas aplicáveis;

Avaliação de profissional qualificado.

As hipóteses são geradas por regras heurísticas pré-programadas. Não há cálculo de probabilidade estatística. A confirmação de causa depende sempre de verificação no equipamento real.

📋 Dados e Privacidade
Todas as informações ficam armazenadas no localStorage do seu navegador.

Nada é enviado para servidores externos.

Os dados podem ser perdidos se o armazenamento local for apagado.

Não há sincronização entre dispositivos.
